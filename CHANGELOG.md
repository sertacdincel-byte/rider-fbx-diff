# Changelog

## 1.0.0 — 2026-11-05

- First release.
- FBX diff viewer: two synchronized 3D panes for any two-sided diff of an `.fbx` (Git history, local changes, branch compare, compare files).
- Single-file viewer when an `.fbx` is opened in the editor.
- Statistics with deltas: per-mesh triangles, vertices (≈ Unity), unique positions, bones, blend shapes, UV sets, materials; LOD totals; animation clips; material usage; file size, FBX version, exporter.
- Clay / Original / Normals shading, wireframe, skeleton, grid, rotation fix, LOD filter, animation playback, mesh highlight.
- Files over 256 MB are not previewed.
